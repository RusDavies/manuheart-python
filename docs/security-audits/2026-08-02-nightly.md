## Findings

### Fixed: HTTPS group URL scheme validation

Severity: P3 low.

Evidence: `src/manuheart/config.py` accepted both `http://` and `https://` URLs for
groups declared as `type: "https"`, which could silently downgrade a supposedly
HTTPS health check to plaintext HTTP.

Remediation: HTTPS groups now require `https://`; HTTP groups continue to allow
either `http://` or `https://`.

Regression coverage: `tests/test_config.py` covers rejection of `http://` URLs
for HTTPS groups and acceptance of `https://` URLs for HTTP groups.
